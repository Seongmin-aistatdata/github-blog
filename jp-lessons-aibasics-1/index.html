人工知能の基本 ― 第1回（ver.261022-1）

今回の記事は、次のキーワードに関連しています。
#人工知能 #機械学習 #ディープラーニング #学習 #モデル #パターン #特徴

人工知能とは何でしょうか？ 一言でまとめるなら、

人間が行う知的な作業を、機械によって自動化するための、最も広い概念です。

でも、「人工知能は、一体何をどうやって、人間の知的な作業を代わりに行うんですか？」と思うかもしれませんね。それでは、説明していきます。

人間がデータなどの入力を与えると、その中から共通する特徴、つまりパターンをコンピューターが自ら見つけ出す。これが人工知能の手法です。そして、その手法は数え切れないほどあります。その一つがTransformerです。ChatGPTのような大規模言語モデルの中核を担うTransformerは、言葉の特徴を捉えることが得意な人工知能の手法だと言えるでしょう。

そして、特徴を捉えた後は、それを利用して、人間が行っている知的な作業を代わりに行えるようになります。

捉えた特徴をもとに、何かを出力・生成する仕組みや、人間の作業を代わりに行う機能をあれこれ組み合わせると、私たちがよく知っているChatGPTのような生成AIができあがります。こうして、人間が行う作業を代わりにこなせるようになるわけです。

例えば……

友人から、ある人の行動を毎日観察して書き留めたノートを渡されたとしましょう。

自分で読みながら、「この人には、こういう特徴やパターンがあるんだな……」と考えることもできますよね。

でも、ノートの内容を分析して、その人に共通する特徴を抽出できる人工知能の手法があるなら、そのAIにノートの内容を入力するだけで、パターンを取り出してもらえるわけです。

人工知能は、この過程で私たちが見落としていたパターンを見つけることもあります。

例えば、私たちは「この人には、態度が悪いというパターンがある」と捉えたとします。一方でAIは、文章の中から、その原因につながる特徴まで見つけるかもしれません。

つまり、人工知能の手法はパターンを見つける方法でもあり、入力されたデータの中から、人間が気づかなかった共通のパターンを捉えることもできる、ということです。

この強みが特に発揮されるのは、入力やデータの量がとてつもなく多いときです。

例えば、100万行、3,000万列もあるCSVファイルから、パターンを見つけなければならないとしましょう。全部に目を通そうとしたら、一生そのCSVの分析だけで終わってしまうかもしれません（笑）。

でも、そのCSVから、知りたいパターンを分析したり、調べたいことを把握したりできる人工知能の手法を使ったとしたら、どうでしょうか。

私たちが一つひとつ確認しなくても、それを可能にしてくれるわけです。

人生が楽になりますね……たぶん？

さて、AIの時代と言われる今、人工知能の手法について、いろいろな名前を耳にしたことがあると思います。

例えば、Transformer、ニューラルネットワーク、ランダムフォレストなどなど……。多すぎて、混乱してしまいますよね。

人工知能が何かは何となく分かった。でも、「結局、どれが人工知能なの？ 絶対に区別できるようになってやる!!!!」と思いましたか？

AI ⊃ ML ⊃ DL

この関係を覚えておいてください！

ちなみに、**⊃**という記号の意味は、次の例で覚えてください。

例えば、A ⊃ Bなら、

→ AはBのすべての要素を含み、さらにAにはBにない要素もある、という意味です。

  • A = {1, 2, 3}
  • B = {1, 2}

したがって、A ⊃ Bとなります。

人工知能は、人間が行う知的な作業を、機械によって自動化するための、最も広い概念だと定義しましたね。

その中で、ML＝機械学習は、人間がすべてのルールを直接プログラムする代わりに、データと正解・目標を使って、コンピューターにルールを学習させるAIの実現方法です。

このような方法で、人間が行う作業をコンピューターに代わりに行わせることができます。

例えば、いろいろな花の特徴をまとめた表があるとしましょう。特徴としては、花びらの面積や花の色などがあるとします。

これを表にすると、花1、花2……というように、花が一つずつ行に並びます。そして、それぞれの特徴を列に並べます。

ここで、機械学習の手法、つまり大きく見れば人工知能の手法の一つを使って、「こういう特徴があれば、この花である」というルールをコンピューターが学習したとしましょう。

そうすると、新しい花が何の花なのか分類したいときには、学習させたコンピューターにその花の特徴を入力すれば、コンピューターが分類してくれるようになるのです。

でも、ここでも疑問が浮かぶかもしれません。

そもそも「学習」って、何なのでしょうか？

AIにおける学習とは、簡単に言えば、モデルが持つ数値を、パターンをうまく表せる数値へと調整していく、一連の過程のことです。

そして、この学習の結果として得られるものが、学習済みモデルです。

でも、また疑問が出てきますよね？

そもそも、モデルって何ですか……？

次のように考えてみてください。

  1. 現実の現象を数学的に表した仕組み。
  2. データを処理したり、予測したりする仕組み。

まだよく分からないという方のために、もう少し説明していきます。

例えば、線形回帰モデルを使って考えてみましょう。線形回帰は、AIの手法、もう少し範囲を絞ると、機械学習の手法の一つです。

まずは、理解しやすくするために、図を一つ加えてみましょう。

ここでは、x軸とy軸のある座標平面が目に入ると思います。

私たちが持っているデータは、**(x, y) = (1, 2)**のような組になっているとしましょう。

こうしたデータを座標平面上に示すと、青い点のように並びます。

でも、x = 4のときのyの値を知りたいのに、そのときのデータがなかったら、どうすればよいのでしょうか？

線形回帰モデルを使って、x = 4のときのyの値を予測してみることができます。

線形回帰モデルは、次の式で表されます。

y = wx + b

私たちの目標は、**(x, y)**のデータを使って、wとbという数値を学習によって決めることです。

直感的に考えてみましょう。手元にあるデータをもとに、例えばx = 4のときにy = 4になると予測したいなら、図にあるような直線を引きたいですよね。

ほとんどy軸みたいに急な傾きの直線を引いてしまっては、困るわけです。

そこで、頭のいい方々が、そうした直線にならないように、データによく合う直線を求める方法を、すでに考えてくれています。

つまり、線形回帰モデルを学習させる方法です。

その一つが、各点のyの値と、直線が予測するyの値との差、つまり残差の二乗和を最小にする方法です。最小二乗法などが、これに当たります。

こうして学習させて、つまりwやbという数値を調整して一次式に入れて得られるものが、学習済みの線形回帰モデルです。

線形回帰モデルは、数学的にデータを処理したり、予測したりする仕組みの一つです。そのような仕組みを、ここではモデルと呼んでいるわけですね。

それでは、「人工知能の基本」第1回はここまでです。
