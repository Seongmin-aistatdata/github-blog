The Basics of Artificial Intelligence — Part 1 (ver.261022)

This post is related to the following keywords:
#ArtificialIntelligence #MachineLearning #DeepLearning #Learning #Models #Patterns #Features

What is artificial intelligence? To put it in one sentence:

The broadest concept of enabling machines to automate intellectual tasks performed by humans.

But you might be wondering, “How exactly does artificial intelligence do the intellectual work that people do?” Well, let me explain.

When people provide inputs—such as data—AI methods allow computers to discover shared features, or patterns, within those inputs on their own. There are countless methods for doing this. One of them is the Transformer. The Transformer architecture, a core component of large language models such as those behind ChatGPT, can be described as an AI approach that is particularly good at identifying patterns in language.

Once those features have been identified, they can be used to carry out intellectual tasks that humans would otherwise perform.

If we build on those identified features and add components that produce outputs, generate content, or perform tasks that people normally do, we get generative AI systems such as ChatGPT. That is how these systems can take over some of the work people do.

For example…

Imagine that a friend gives you a notebook containing daily observations of someone’s behavior.

You could read through it yourself and think, “Okay, this person seems to have these characteristics or patterns.”

But if there is an AI method that can analyze the notes and identify those recurring characteristics, you can simply feed the contents into it and have it extract the patterns for you.

AI may even discover patterns that we missed. For example, we might conclude that someone has a pattern of being rude, while AI might identify something in the notes that points to a reason behind that behavior. In other words, AI methods can identify patterns—including shared patterns in the inputs or data that people might not notice.

This becomes especially useful when there is an enormous amount of input or data.

Imagine having to identify patterns in a CSV file with one million rows and thirty million columns. You might spend the rest of your life analyzing that one file. (Maybe?)

Now imagine using an AI method that can analyze the patterns you are interested in or find what you want to examine in that CSV file. It lets you do this without having to inspect every single entry yourself.

Life gets easier… right?

By now, in this age of AI, you have probably heard of plenty of AI methods.

Transformers, neural networks, random forests, and so on and on… There are so many that it can get confusing.

Now that you have an idea of what AI is, are you thinking, “But which things actually count as AI? I’m going to figure this out once and for all!!!!”?

AI ⊃ ML ⊃ DL

Remember this relationship!

For reference, here is what the symbol ⊃ means.

For example, A ⊃ B means:

→ A contains every element of B, and A also contains elements that are not in B.

  • A = {1, 2, 3}
  • B = {1, 2}

Therefore, A ⊃ B.

Keep this example in mind when you see the symbol.

We defined artificial intelligence as the broadest concept of enabling machines to automate intellectual tasks performed by humans.

Within that broad concept, ML, or machine learning, is an approach to implementing AI in which computers learn rules from data and answers or objectives, rather than having people explicitly code every rule. This allows computers to perform tasks that people would otherwise do.

For example, imagine that we have a table containing the characteristics of different flowers. Let’s say those characteristics include petal area and flower color.

In this table, each flower—flower 1, flower 2, and so on—would occupy a row. The characteristics would go in the columns.

Now suppose we use a machine learning method—which is itself one type of AI method—to teach a computer rules about which characteristics correspond to which flowers.

If we then want to classify a new flower, we can enter its characteristics into the computer we trained, and it can classify the flower for us.

But this might raise another question.

What exactly does “learning” mean?

In AI, learning can be described, in brief, as the entire process of adjusting a model’s numerical values so that they describe patterns well. What we get at the end of this learning process is a trained model.

But that raises yet another question, doesn’t it?

What is a model, anyway?

You can think of it as:

  1. A structure that represents a real-world phenomenon mathematically.
  2. A structure that processes data or makes predictions.

If that still feels a little abstract, let me explain further.

Let’s use a linear regression model as an example. Linear regression is one of the methods used in AI—or, more specifically, machine learning.

First, let’s add a visual to make this easier to understand.

The main thing you can see here is a coordinate plane with an x-axis and a y-axis.

Suppose our data consists of pairs such as (x, y) = (1, 2).

When we plot these data points on the coordinate plane, they appear as the blue dots.

But what if we want to know the value of y when x = 4, and we do not have an observation for that?

We can use a linear regression model to predict the value of y at x = 4.

The linear regression model is:

y = wx + b

Our goal is to use the (x, y) data to learn the numerical values of w and b.

Think about it intuitively. If we want to predict a value such as y = 4 when x = 4, based on the data we have, we would want to draw a straight line like the one in the figure. We would not want a line so steep that it almost looks like the y-axis, right?

Well, some very clever people have already developed methods for fitting a straight line to the data without ending up with a line like that. In other words, they have developed methods for training a linear regression model.

One such approach is to minimize the sum of the squared differences—the residuals—between the observed y-values and the values predicted by the line. This is the idea behind methods such as least squares.

The result of this training—adjusting the numerical values of w and b and putting them into the linear equation—is a trained linear regression model.

So, a linear regression model is one example of a mathematical structure for processing data or making predictions. That is what we mean by a model here.

That wraps up Part 1 of The Basics of Artificial Intelligence.
